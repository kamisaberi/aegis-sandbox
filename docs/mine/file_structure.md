Here is the complete, production-grade file structure for **Project #2: `aegis-sandbox`** (*Sub-10ms Firecracker MicroVM & eBPF Isolation Engine for Autonomous AI Agent Code*).

This project combines **C++20** (for low-latency native execution and policy enforcement), **C** (for eBPF kernel probes), **Go** (for the gRPC control-plane daemon and Firecracker API orchestration), and **Firecracker KVM microVMs** to provide zero-trust isolation for AI agents.

### Key Architectural Highlights
1. **Dual Language Engine:** **Go** handles the gRPC daemon and Firecracker SDK orchestration, while **C++20** handles low-latency native execution, TAP networking, and cgroups v2.
2. **Kernel eBPF Probes:** C code in `ebpf/` compiles directly to BPF bytecode using Clang and attaches to kernel tracepoints to block unauthorized syscalls and SSRF egress (blocking `169.254.169.254`).
3. **Sub-10ms Boot via Snapshots:** Uses `prewarm_snapshots.sh` to load pre-booted microVM memory states from disk via KVM copy-on-write memory mapping.
